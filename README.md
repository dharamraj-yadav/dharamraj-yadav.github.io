# dharamraj-yadav.github.io

Personal academic and portfolio website of Dharamraj Yadav.

Built with [Hugo](https://gohugo.io/) and the [HugoBlox](https://github.com/HugoBlox/kit) academic-cv template, deployed via GitHub Pages.

## Local development

```bash
hugo server
```

## Deployment

Pushing to `main` automatically rebuilds and republishes the site via GitHub Actions (`.github/workflows/deploy.yml`).

Remember: local edits only take effect after `git add`, `git commit`, and `git push` — saving a file alone does not update the live site.
